# Integration guide — v0.1.0

Baseline public surface for the first tagged **Android** SDK release.

## Who should read this

Host apps integrating Diverge SDK for the first time on Android (local module / future Maven Central).

iOS: see [Diverge-SDK-iOS](https://github.com/askdiverge/Diverge-SDK-iOS).

## Public API

```kotlin
import ai.askdiverge.sdk.Configuration
import ai.askdiverge.sdk.Diverge
import ai.askdiverge.sdk.Environment

Diverge.configure(
    Configuration(apiKey = "sk_sandbox_...", environment = Environment.SANDBOX)
)
val client = Diverge.shared
```

### Environments

| Environment | `wireName` | API base URL |
|-------------|------------|--------------|
| `SANDBOX` | `sandbox` | `https://sandbox.api.askdiverge.ai` |
| `PRODUCTION` | `production` | `https://api.askdiverge.ai` |

No live network calls are made by `configure` in v0.1.0.

## Breaking changes

None — initial public surface.
