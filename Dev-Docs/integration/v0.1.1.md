# Integration guide — v0.1.1

Host apps upgrading from `v0.1.0` to `v0.1.1` on Android.

## Breaking changes

None for the public configure API.

## Migration steps

1. Bump the dependency to `0.1.1` (local module or Maven when published).
2. No code changes required for configure / StatusView hosts.

## Notes

- Paparazzi goldens are now committed; CI fails on StatusView UI drift.
- Unused `androidx.core:core-ktx` was removed from the library AAR.
