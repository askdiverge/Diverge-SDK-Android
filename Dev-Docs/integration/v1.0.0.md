# Integration guide — v1.0.0

## Who should read this

Host apps integrating the Diverge chat on Android for the first time, and any host built against
the `v0.1.0` GitHub tag. `1.0.0` is the first version published to Maven Central.

## Breaking changes

| Area | Before (0.1.0) | After (1.0.0) | Action |
|------|----------------|---------------|--------|
| Entry point | `Diverge.configure(Configuration(...))`, `Diverge.shared` | `ChatbotBottomSheet(...)` composable | Show the sheet where the host opens the chat |
| Credentials | API key in `Configuration` | Session token from the host backend through `ChatbotCallbacks` | Implement `ChatbotCallbacks`; never ship an API key |
| Environment | `ai.askdiverge.sdk.Environment` (`SANDBOX`, `PRODUCTION`) | `ai.askdiverge.DivergeEnvironment` (`PRODUCTION`, `DEVELOPMENT`) | Pass `environment` only to target development |
| UI | `DivergeStatusView` (View) | Jetpack Compose, Material 3 | Host a Compose surface for the sheet |
| Errors | `DivergeException` | `ChatbotException` (`SessionExpired`, `NoTokenAvailable`) | — |

## Migration steps

1. Depend on the release:

   ```kotlin
   implementation("ai.askdiverge:diverge-sdk:1.0.0")
   ```

2. Implement `ChatbotCallbacks` against the host backend. Each hook is a `suspend` function
   returning `Result`:
   - `fetchToken()` returns the visitor's session token, issuing one if there is none yet.
   - `createNewToken()` replaces the session; the conversation restarts empty.
   - `deleteChatData()` deletes the visitor's chat data.
   - `sessionInvalidations()` (optional) emits after login or logout so the chat fetches the
     token again.
3. Show `ChatbotBottomSheet(chatbotCallbacks = ..., onDismiss = ...)` while the chat is open.
   Optional parameters: `currentPage`, `fontFamily`, `onUrlClick`, `environment`.
4. Optionally call `ChatbotLogger.install(...)` once to receive the SDK's error logs. Nothing is
   logged until a logger is installed.
5. Remove every use of the 0.1.0 API listed above.

## New permissions / privacy

- Manifest permissions: none declared by the library. The host supplies `INTERNET`.
- `currentPage` is sent to the Diverge backend with each message. It describes the screen and must
  not identify the person.
- The SDK stores no tokens or conversation data on disk.
