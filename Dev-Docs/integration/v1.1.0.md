# Integration guide — v1.1.0

## Who should read this

Host apps upgrading from `1.0.0` to `1.1.0` on Android. The upgrade compiles without code
changes; one default changes what the visitor sees when the chat closes.

## Breaking changes

| Area | Before (1.0.0) | After (1.1.0) | Action |
|------|----------------|---------------|--------|
| Closing the chat | `onDismiss` ran as soon as the visitor closed the sheet | After the visitor has sent a message, closing may first show a 1–5 rating (`POST /chat/rate`); `onDismiss` runs after it | Nothing, or pass `rating = ChatbotRating.DISABLED` to close at once |

## Migration steps

1. Depend on the release:

   ```kotlin
   implementation("ai.askdiverge:diverge-sdk:1.1.0")
   ```

2. Decide on the close rating. `rating` defaults to `ChatbotRating.ENABLED`. Pass
   `ChatbotRating.DISABLED` if the host must close the chat immediately. Livechat's own rating
   (CSAT) is not affected by this parameter.
3. Optional new parameters on `ChatbotBottomSheet`, all with defaults, passed by name:
   - `attachments = ChatbotAttachments.PHOTO_LIBRARY` lets the visitor send photos to the
     assistant and to a live agent, through the Android Photo Picker. The default, `DISABLED`,
     offers no photo controls.
   - `onLivechatSessionChange = { info -> … }` reports whether the visitor is queued, talking to
     an agent (with the agent's name) or the session has ended, so the host can show it in its
     own UI. It is delivered only while the sheet is shown.
   - `currentPage` (already in 1.0.0) now also picks the in-chat banners for that page.
4. Nothing else changes in `ChatbotCallbacks`. After `/config` rejects the visitor token, the SDK
   now calls `fetchToken()` again, so return the host's current, valid token from it.

## New permissions / privacy

- Manifest permissions: none declared by the library. The host supplies `INTERNET`. The Photo
  Picker needs no storage permission.
- Download my data: Privacy & Data gains a row that lets the visitor save an export of their data
  (`GET /chat/export`) to a document they create in the system save dialog. The SDK keeps no copy.
  Mention it in the host's privacy notice if the host lists what the chat can do.
- Livechat handover sends the agent the device language, `os: "Android"` and `currentPage`
  (cut to 2,048 characters). `currentPage` must describe the screen, never the person.
- Apart from that export, the SDK still stores no tokens or conversation data on disk.

## Backend requirements

- In-chat banners need `GET /api/v1/chat/banners` on the Diverge backend. Until that route is
  deployed, the request is refused and no banner is shown; the chat works normally.
